RESİM KLASÖRÜ  /  SURAT PAPKASY  /  ПАПКА С КАРТИНКАМИ
======================================================

Buraya resim koyarsan bot o ekranı fotoğraflı gönderir.
Resim yoksa hiçbir şey bozulmaz, sadece yazı gönderilir.

Dosya adları (jpg / png / webp olabilir):

  karsilama.jpg   -> bota ilk girişte
  menu.jpg        -> ana menü
  para.jpg        -> gerçek para ekranı
  oyunlar.jpg     -> oyunlar ekranı
  hediye.jpg      -> günlük hediye
  market.jpg      -> market
  yardim.jpg      -> nasıl oynanır
  duello.jpg      -> düello
  canavar.jpg     -> canavar/boss
  kazandin.jpg    -> büyük kazanç

Önerilen boyut: 1280x720 (yatay), 300 KB altı.

Resmi ekledikten sonra:
  systemctl restart coinquest
